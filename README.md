# SanKou Lee Personal Homepage

这是一个简单的静态个人主页，不依赖图片文件，适合直接上传到 GitHub 或开启 GitHub Pages。

## 文件

- `index.html`：页面内容
- `styles.css`：页面样式

## 修改建议

打开 `index.html`，把以下内容替换成你自己的信息：

- `hello@example.com`
- GitHub 链接
- LinkedIn 链接
- 作品与经历里的项目描述

## GitHub Pages

把这三个文件上传到仓库根目录，然后在仓库的 `Settings > Pages` 中选择对应分支即可发布。
